# Change history and design decisions

Running log of what changed in the generator and why, plus the user's review feedback kept VERBATIM.

- `NNNN-short-title.md`: one entry per change or decision (ADR style: Context, Decision, Consequences, Commits).
- `feedback/`: the user's typed notes and messages, copied verbatim (never paraphrased), each with the images they refer to (in `images/`).
- Rule: when new user feedback arrives (chat messages, grid notes), save it here verbatim with its screenshots in the same turn, then summarise in the ADR.
- Entries are dated; use real timestamps from git (`git log`).
